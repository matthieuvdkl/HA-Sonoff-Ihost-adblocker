# AdGuard Home (iHost)

Bloqueur de publicités et de traqueurs pour tout le réseau, sous forme de
serveur DNS, empaqueté pour le **Sonoff iHost** sous Home Assistant OS.

L'add-on communautaire officiel n'est plus publié pour les processeurs ARM
32-bit (armv7) depuis Home Assistant 2025.12. Celui-ci est construit
directement sur l'iHost à partir de l'image Docker officielle d'AdGuard Home,
qui reste disponible en armv7.

Voir l'onglet **Documentation** pour l'installation et la configuration.
